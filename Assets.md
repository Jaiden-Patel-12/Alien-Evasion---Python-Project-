# Game Assets

The following assets were used during the development of **Alien Evasion**.

| Asset | Type | Purpose |
|-------|------|---------|
| `title_font.TTF` | TrueType Font (.TTF) | Main font used for the game title, Game Over screen and menu text. |
| `font_one.TTF` | TrueType Font (.TTF) | Font used for displaying the player's score during gameplay. |
| `other_screen.jpg` | JPEG Image | Background image used across the start, gameplay and Game Over screens. |
| `welcome.wav` | WAV Audio | Played once when the game is launched. |
| `ufo_image.png` | PNG Image | First of four possible UFO player sprites selected at random. |
| `ufo_image_two.png` | PNG Image | Second random UFO sprite. |
| `ufo_image_three.png` | PNG Image | Third random UFO sprite. |
| `ufo_image_four.png` | PNG Image | Fourth random UFO sprite. |
| `alien_image.png` | PNG Image | Alien obstacle displayed during gameplay. |
| `ufo_sound.mp3` | MP3 Audio | Played whenever the player presses the Space bar. |
| `explosions.mp3` | MP3 Audio | Played when the UFO collides with an alien or leaves the screen. |
| `point_sound.mp3` | MP3 Audio | Played each time the player earns a point. |
