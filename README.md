# Alien-Evasion---Python-Project-

A 2D arcade-style arcade game developed in Python using Pygame as part of my BTEC Extended Diploma in Information Technology.

## Features
- Player-controlled spaceship
- Random obstacle generation
- Collision detection
- Score tracking
- Multiple difficulty levels
- Game over and restart functionality
- Interactive sounds

## Technologies Used

- Python
- Pygame
- Random
- Visual Studio

## Skills Demonstrated

- Object-oriented programming
- Debugging and testing
- Event handling
- Collision detection
- Game logic
- Problem solving

## About the Project

This project was built from scratch and consists of approximately 2300 lines of Python code. During development I solved programming challenges such as obstacle scaling, collision detection accuracy and gameplay balancing through iterative testing.
